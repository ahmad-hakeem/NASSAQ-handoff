
شكراً على التقرير المفصل.
المطلوب الآن هو **استكمال وتنفيذ جميع الأجزاء الجزئية والغير منفذة** في رحلة **End Session Journey** بحيث تصبح الرحلة **مكتملة 100% ومتوافقة مع منطق النظام بالكامل**.

يرجى تنفيذ العناصر التالية بدقة، مع الحفاظ على **تكامل قاعدة البيانات، Event Log، وارتباط جميع البيانات بمحركات النظام الأخرى**.

# 1 — استكمال شروط إنهاء الحصة (7.3)

حالياً يتم التحقق من:

* session status = in_progress
* attendance recorded

المطلوب إضافة التحقق من الشروط التالية قبل السماح بإنهاء الحصة:

### 1.1 التحقق من مالك الحصة

يجب التأكد أن المعلم الذي يحاول إنهاء الحصة هو **صاحب الحصة الفعلي**.

```pseudo
if session.teacher_id != current_user.id:
    reject_action("You are not the owner of this session")
```

---

### 1.2 التحقق من استقرار الاتصال

قبل إنهاء الحصة يجب التحقق من:

* عدم وجود طلبات pending
* عدم وجود عمليات حفظ غير مكتملة

إذا كان هناك عمليات غير مكتملة يظهر تنبيه:

"هناك عمليات لم تكتمل بعد. يرجى الانتظار."

---

### 1.3 التحقق من اعتماد الحضور

لا يمكن إنهاء الحصة إذا لم يتم:

```
attendance_status = approved
```

---

# 2 — تحديث ملف الطالب عند إنهاء الحصة (Student Profile Update)

حالياً يتم تحديث النقاط أثناء التفاعل فقط.

المطلوب:

عند إنهاء الحصة يجب تنفيذ **Student Profile Update Transaction**.

يتم تحديث:

### لكل طالب

```
student_profile
```

يتم تحديث:

* total_sessions_attended
* total_participations
* behavior_score
* skill_progress
* last_session_date
* engagement_score

---

### تنفيذ العملية في Transaction واحدة

```
update_student_profile_after_session(session_id)
```

حتى يتم ضمان:

* عدم تضارب البيانات
* حفظ التحديثات بشكل متكامل

---

# 3 — إرسال البيانات إلى Reports & Analytics Engine

عند إنهاء الحصة يجب تشغيل **Pipeline تحليل البيانات** تلقائياً.

تنفيذ:

```
trigger_reports_engine(session_id)
```

يجب أن يقوم المحرك بحساب:

* attendance_rate
* engagement_rate
* behavior_distribution
* skill_progress_distribution
* class participation score

ثم يتم إرسال البيانات إلى:

```
school_analytics
teacher_analytics
class_analytics
```

---

# 4 — تشغيل AI Insight Engine تلقائياً

بعد إنهاء الحصة مباشرة يجب تشغيل:

```
AI Insight Engine
```

الهدف:

تحليل الحصة وإنتاج:

### AI Classroom Insights

مثل:

* الطلاب الأكثر نشاطاً
* الطلاب الذين يحتاجون متابعة
* نمط المشاركة داخل الفصل
* تحسن الأداء

يتم حفظ النتائج في:

```
ai_session_insights
```

---

# 5 — تنبيهات ذكية تلقائية (Smart Notifications)

بدلاً من الاعتماد على زر يدوي، يجب تشغيل التنبيهات تلقائياً.

عند إنهاء الحصة يتم تشغيل:

```
Notification Engine
```

ويتم إنشاء التنبيهات التالية:

---

### 5.1 تنبيه غياب الطالب

إذا كان:

```
attendance = absent
```

يتم إرسال إشعار لولي الأمر.

---

### 5.2 تنبيه السلوك السلبي المتكرر

إذا كان الطالب سجل:

```
negative_behavior >= 3
```

يتم إرسال تنبيه:

* لولي الأمر
* لمدير المدرسة

---

### 5.3 تنبيه التحسن الملحوظ

إذا تحسن الطالب مقارنة بالحصة السابقة:

```
engagement_increase > threshold
```

يتم إرسال إشعار إيجابي لولي الأمر.

---

# 6 — إضافة مؤقت الحصة (10 Minutes Warning)

يجب إضافة **Session Countdown Timer** في واجهة الحصة.

قبل نهاية الحصة بـ **10 دقائق** يظهر تنبيه بصري:

```
تبقى 10 دقائق على نهاية الحصة
```

ويظهر أيضاً:

```
زر "إنهاء الحصة"
```

مع تغيير لون الزر إلى **Primary Highlight**.

---

# 7 — تصدير تقرير الحصة

### زر

* معلومات الحصة

* الملاحظات
* AI Insights
