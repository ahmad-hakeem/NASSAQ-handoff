Create a complete Design System, UI Rules, and Component Styling Standards document for the internal NASSAQ system:

Product Intelligence Hub
(مركز ذكاء المنتج)

This is an INTERNAL enterprise system.
The visual direction must feel premium, highly structured, polished, modern, and efficient for daily operational use.

This task is NOT about building business logic.
This task is about defining the visual system and interface standards that all frontend work must follow consistently.

==================================================
1) DESIGN OBJECTIVE
==================================================

Build a visual and component system that ensures:

- consistency across all pages
- enterprise-grade polish
- clean and calm interface
- high readability
- easy scanning
- low clutter
- clear hierarchy
- support for visible AI assistant UI (Hakim)
- smooth bilingual Arabic/English support
- RTL/LTR parity
- easy use by non-technical internal staff

The result must function as the single source of truth for UI execution.

==================================================
2) BRAND / VISUAL DIRECTION
==================================================

The interface should feel like:

- premium enterprise software
- calm operational control center
- structured product intelligence workspace
- modern internal SaaS dashboard
- intelligent but not flashy
- refined and trustworthy

Tone of UI:
- serious
- elegant
- practical
- modern
- clear
- quietly intelligent

Avoid:
- visual noise
- over-decoration
- crowded layouts
- excessive gradients
- childish visuals
- random icon sizes
- inconsistent spacing
- too many competing colors

==================================================
3) CORE DESIGN PRINCIPLES
==================================================

Define and enforce the following principles:

1. No-Brain UX
- users should immediately understand what to do
- important actions should be obvious
- reduce cognitive load

2. Progressive Disclosure
- reveal complexity only when needed
- avoid overwhelming forms and details pages

3. Visual Hierarchy First
- title, status, priority, owner, and actions must always be easy to scan

4. Enterprise Clarity
- every card, badge, and table should feel structured and purposeful

5. AI Visibility with Restraint
- Hakim should be clearly visible but never noisy or gimmicky

6. Bilingual Integrity
- Arabic and English should both feel native
- RTL/LTR must be treated as first-class design rules
