PHASE 3: Talents & Skills + Behavior & Character Tabs
Goal: Build the two behavioral and personal development tabs

3.1 Talents & Skills Tab (المواهب والمهارات)
Talent Badges Section:

All assigned talents displayed as visual cards
Each card: icon + talent name + proficiency level (Beginner / Intermediate / Advanced)
"+ Add Talent" button opens modal with:

Predefined talent list (dropdown)
Option to type and add a custom talent
Custom talents are saved to the global talent list for reuse


Each talent card has a remove (×) button
isGifted flag auto-updates based on whether talents exist

Skills Radar Chart (new):

Hexagonal/polygon radar chart mapping 6 dimensions:

Academic · Creative · Athletic · Technical · Social · Leadership


Updates dynamically as talents are added or removed

Future Career Affinity Section (placeholder — AI-ready):

Based on current talent tags, display suggested career clusters
Example: "Strong indicators toward: Engineering, Medicine, Research"
Clearly labeled: "Early Indicators — Not Final. This section will be AI-powered in a future version."


3.2 Behavior & Character Tab (السلوك والشخصية)
Summary Counter Cards (top of tab):

✅ Total Positive: X
❌ Total Negative: X
📊 Total Records: X

Behavior Trend Chart (new):

Monthly bar chart: positive (green bars) vs negative (red bars) incidents over time
Gives a visual behavioral history at a glance

Behavior Log:

Chronological list of all behavior records
Each card shows: type badge (green/red), category, description, date, added by
Edit and delete icons on each card
Paginated if more than 10 records

Add Behavior Button:

Opens modal with:

Type toggle: Positive / Negative
Category dropdown (predefined per type + custom option)
Description text area
Date (auto today, editable)



Character Traits Section (new):

Separate from behavior incidents
Positive personality tags added by teachers over time
Examples: Responsible · Empathetic · Creative · Leader · Persistent · Curious
Displayed as soft-colored pill tags
Add / remove individual traits


Deliverable for Phase 3:
Both tabs fully functional. Radar chart rendering. Behavior log connected to database. Character traits saved and persisted.
