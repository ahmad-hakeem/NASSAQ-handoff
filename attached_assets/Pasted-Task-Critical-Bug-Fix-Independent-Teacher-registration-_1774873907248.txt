Severity: CRITICAL
This bug breaks the approval workflow for independent teachers inside NASSAQ.

The issue is still not resolved.

Login Page → "تسجيل جديد"

"إدارة المستخدمين"

   - "طلبات المعلمين المستقلين"

7. Be available for approval / rejection by Platform Admin
