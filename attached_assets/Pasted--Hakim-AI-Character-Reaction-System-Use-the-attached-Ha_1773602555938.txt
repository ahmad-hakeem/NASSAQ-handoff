## Hakim AI Character Reaction System

Use the attached Hakim character images as a **dynamic AI assistant across the NASSAQ system**.

Hakim is the **AI intelligence layer of the platform** and should appear in different parts of the system to guide, explain, celebrate, alert, and interact with users.

Hakim must not behave like a static mascot.

He must feel like a **living intelligent assistant that reacts to context, events, and user actions.**

The system should dynamically choose from the provided **Hakim poses** depending on the situation, user action, and system state.

Hakim should appear in:

• dashboards
• onboarding screens
• help panels
• AI insights sections
• alerts and notifications
• student dashboards
• teacher workflow moments
• system success states

The goal is for users to feel that **there is an intelligent system actively assisting them in the background.**

# Dynamic Pose Rotation

Do not always show the same pose.

Allow the system to randomly select between **2–3 relevant poses for the same context**.

Example:

When schedule creation is completed:

Possible poses:

Positive feedback pose
Motivating pose
Congratulating student pose

Choose randomly to create variation.

---

# Behavior Design Goal

Hakim must feel like a **living intelligent assistant**.

The user should feel:

• the system is aware of what is happening
• the AI reacts to actions
• the interface is alive and intelligent

Hakim should enhance the feeling of **AI-powered interaction inside the platform.**

---

# Important Design Tip (Animation Levels)

Hakim should have **3 animation levels** to make the system feel alive.

### 1️⃣ Idle Animation

Very subtle movement.

Examples:

breathing motion
slight floating
small head movement
soft blinking

Used when Hakim is simply present.

---

### 2️⃣ Interaction Animation

Triggered when the user interacts.

Examples:

pointing
hand gestures
explaining movement
slight body shift

Used when Hakim is guiding or explaining.

---

### 3️⃣ Celebration Animation

Used when the system detects success.

Examples:

clapping
small celebratory motion
happy gesture

Used after achievements or completed tasks.

---

# Final Goal

Hakim should transform the interface from a **static software system** into a **living AI-powered educational environment**.

The character must:

• guide users
• react to actions
• celebrate success
• assist learning
• highlight insights

Hakim should feel like the **intelligence behind NASSAQ**, not just a visual mascot.
