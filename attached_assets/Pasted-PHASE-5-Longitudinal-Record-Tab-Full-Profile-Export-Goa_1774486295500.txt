PHASE 5: Longitudinal Record Tab & Full Profile Export
Goal: Build the long-term career-readiness layer and complete export system

5.1 Longitudinal Record Tab (السجل التراكمي)
This is the most strategic tab — the foundation of the future career matching engine.
Student Journey Timeline:

Year-by-year vertical timeline from enrollment to current grade
Each year card contains:

Grade and class
Assigned teacher
Attendance rate for that year
Top 3 talents that year
Behavior summary (positive/negative count)
Key achievements or awards
Academic performance average



Skill Growth Tracker (new):

Line chart showing how each talent/skill proficiency has evolved across years
One line per skill, color coded
Shows clearly which skills are growing, stable, or inactive

Readiness Indicators Section (new — AI-ready placeholder fields):
Display four score indicators (visual gauge or progress bar style):

🎓 Academic Readiness Score
🤝 Social-Emotional Readiness Score
👑 Leadership Potential Score
💼 Career Alignment Score

All labeled clearly as:
"These indicators are based on cumulative data and will be AI-powered in a future version of NASSAQ."
Career Clusters Section (new — placeholder):

Based on all accumulated talent, behavior, achievement, and academic data
Display 3 suggested career cluster cards:

Cluster name (e.g., STEM / Arts / Business / Healthcare)
Match strength percentage
Brief explanation of why this cluster fits the student


Labeled: "Early career affinity indicators — data builds over time"

Vision Statement Banner (bottom of tab):
A subtle, inspiring banner that reads:
"Every data point recorded today is building this student's future. NASSAQ's longitudinal record will power AI-driven career recommendations in the future."
