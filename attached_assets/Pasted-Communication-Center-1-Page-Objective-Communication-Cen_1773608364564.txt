Communication Center
مركز التواصل
1. الهدف من الصفحة (Page Objective)
توفر صفحة Communication Center قناة تواصل رسمية وآمنة داخل النظام تمكّن المعلم من التواصل مع جميع الأطراف المرتبطة بعمله التعليمي، بما يضمن تنظيم التواصل وتوثيقه بشكل احترافي.
تهدف الصفحة إلى:
تسهيل التواصل بين المعلم وإدارة المدرسة.
تمكين التعاون بين المعلمين.
تعزيز التواصل التربوي مع أولياء الأمور.
توثيق جميع الرسائل والمتابعات التعليمية.
ربط التواصل بسياق الطالب أو الفصل أو الحصة.
وتُعد هذه الصفحة مركز الاتصال الرسمي داخل النظام.
2. الجهات التي يمكن التواصل معها (Communication Parties)
يمكن للمعلم التواصل مع عدة جهات داخل النظام وفق الصلاحيات الممنوحة له.
تشمل الجهات:
الجهة	وصف التواصل
إدارة المدرسة	التواصل مع المدير أو الوكلاء بشأن الأمور الأكاديمية أو الإدارية
المعلمون الآخرون	التنسيق بين المعلمين حول الفصول أو الطلاب أو الأنشطة
أولياء الأمور	التواصل مع ولي أمر الطالب بخصوص الأداء أو السلوك أو المتابعة التعليمية


يعتمد النظام على User Identity Graph لتحديد العلاقات بين المستخدمين والسماح بالتواصل وفق هذه العلاقات.
3. أنواع التواصل داخل النظام (Communication Types)
يوفر النظام عدة أنواع من التواصل داخل مركز التواصل.
3.1 الرسائل المباشرة (Direct Messages)
تمكّن المعلم من إرسال رسائل مباشرة إلى:
إدارة المدرسة
معلم آخر
ولي أمر الطالب
يمكن أن تتضمن الرسالة:
نص الرسالة
مرفقات
رابط مرتبط بصفحة داخل النظام
إشارة إلى طالب أو فصل
3.2 الإشعارات التعليمية (Educational Notifications)
يمكن للمعلم إرسال إشعارات تعليمية إلى أولياء الأمور أو الطلاب مثل:
تذكير بواجب
إعلان اختبار
إشعار نشاط تعليمي
إعلان تعليمي عام للفصل
تظهر هذه الإشعارات في:
حساب المستخدم داخل النظام
مركز الإشعارات
3.3 رسائل متابعة مرتبطة بالطالب (Student Follow-up Messages)
يمكن للمعلم إرسال رسائل مرتبطة بملف الطالب مباشرة.
تشمل الرسائل:
متابعة سلوك الطالب
ملاحظة أكاديمية
إشادة بأداء الطالب
تنبيه بضعف الأداء
يتم ربط الرسالة تلقائيًا بملف الطالب داخل النظام.
4. هيكل الصفحة (Page Structure)
تتكون صفحة Communication Center من عدة أقسام رئيسية.
4.1 صندوق الرسائل (Inbox)
يعرض جميع الرسائل الواردة للمعلم.
تشمل المعلومات المعروضة:
اسم المرسل
نوع الرسالة
موضوع الرسالة
تاريخ الإرسال
حالة الرسالة (مقروءة / غير مقروءة)
4.2 الرسائل المرسلة (Sent Messages)
يعرض الرسائل التي قام المعلم بإرسالها.
يمكن من خلاله:
مراجعة الرسائل السابقة
التأكد من وصول الرسالة
متابعة الردود
4.3 إنشاء رسالة جديدة (Compose Message)
يمكن للمعلم إنشاء رسالة جديدة من خلال:
زر: رسالة جديدة
عند الضغط عليه تظهر نافذة تحتوي على:
اختيار الجهة المستقبلة
موضوع الرسالة
نص الرسالة
إرفاق ملفات
ربط الرسالة بطالب أو فصل إن لزم
4.4 الإشعارات المرتبطة بالطلاب (Student Notifications)
يعرض هذا القسم الرسائل المرتبطة بطلاب محددين.
مثل:
إشعار لولي الأمر حول أداء الطالب
رسالة متابعة سلوكية
رسالة إشادة
5. تسجيل العمليات (Communication Log)
يقوم النظام بتسجيل كل عملية تواصل تتم داخل النظام في سجل خاص يسمى:
Communication Log
يتضمن السجل المعلومات التالية:
الحقل	الوصف
المرسل	المستخدم الذي أرسل الرسالة
المستقبل	المستخدم الذي استلم الرسالة
نوع الرسالة	رسالة مباشرة / إشعار / متابعة طالب
المرجع	الطالب أو الفصل المرتبط
محتوى الرسالة	نص الرسالة
تاريخ الإرسال	وقت إرسال الرسالة
حالة القراءة	مقروءة أو غير مقروءة


يساعد هذا السجل في:
توثيق التواصل الرسمي
مراجعة التاريخ التواصلي
دعم الشفافية داخل النظام
6. سلوك النظام داخل الصفحة (System Behavior)
عند فتح صفحة Communication Center يقوم النظام بالخطوات التالية:
التحقق من هوية المستخدم وصلاحياته.
جلب الرسائل الواردة للمعلم.
جلب الرسائل المرسلة.
جلب الإشعارات المرتبطة بالطلاب.
ترتيب الرسائل حسب الأحدث.
عرض الرسائل مع مؤشر القراءة.
7. إرسال الرسائل (Sending Messages)
عند إرسال رسالة يقوم النظام بتنفيذ العمليات التالية:
التحقق من صلاحية الإرسال.
حفظ الرسالة في قاعدة البيانات.
تسجيل العملية داخل Communication Log.
إرسال إشعار للمستلم.
تحديث صندوق الرسائل.
8. الصلاحيات (Permissions)
يستطيع المعلم:
إرسال رسائل لإدارة المدرسة.
التواصل مع المعلمين الآخرين.
التواصل مع أولياء الأمور المرتبطين بطلابه.
إرسال إشعارات تعليمية للفصل.
ولا يستطيع:
التواصل مع أولياء أمور طلاب خارج فصوله.
الوصول إلى رسائل تخص مستخدمين آخرين.
9. سلوك الحالات الخاصة (Edge Cases)
لا توجد رسائل
إذا لم يكن لدى المعلم أي رسائل، يظهر النظام رسالة:
لا توجد رسائل حالياً
رسالة مرتبطة بطالب غير موجود
إذا تم حذف أو نقل الطالب، يتم الاحتفاظ بالرسالة في السجل ولكن مع إظهار تنبيه.
10. تكامل الصفحة مع النظام (System Integration)
ترتبط صفحة Communication Center بالمكونات التالية:
User Identity Engine
Notification Engine
Student Profile Engine
Class Management Engine
Communication Log System
11. تجربة المستخدم (UX Behavior)
يجب أن تكون الصفحة:
بسيطة
واضحة
مشابهة لتجربة تطبيقات المراسلة
سهلة التنقل
كما يجب أن تدعم:
البحث داخل الرسائل
تصفية الرسائل حسب الجهة
تصفية الرسائل حسب الطالب أو الفصل
12. النتيجة النهائية المطلوبة
بعد تنفيذ صفحة Communication Center يجب أن يستطيع المعلم:
التواصل بسهولة مع إدارة المدرسة.
التنسيق مع المعلمين الآخرين.
التواصل التربوي مع أولياء الأمور.
إرسال إشعارات تعليمية.
توثيق جميع عمليات التواصل داخل النظام.
