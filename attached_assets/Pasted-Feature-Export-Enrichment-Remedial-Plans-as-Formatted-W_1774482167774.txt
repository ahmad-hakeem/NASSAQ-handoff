Feature: Export Enrichment & Remedial Plans as Formatted Word Documents
Both teachers and school admins should be able to export student plans as a professionally formatted .docx Word file.

Export Options
For each student who has plans, provide three export choices:

Export Remedial Plan only (الخطة العلاجية فقط)
Export Enrichment Plan only (الخطة الإثرائية فقط)
Export Both Plans together (الخطتين معاً)


Word Document Structure & Design
Each exported file must include a visually attractive, clearly structured layout with the following:
Header Section:

School name (اسم المدرسة)
Teacher name (اسم المعلم)
Student name (اسم الطالب)
Date of export (التاريخ)
Plan type label (Remedial / Enrichment / Both)

Body Section:

Clear section headings for each part of the plan
All relevant plan data, goals, notes, and details
Proper Arabic RTL formatting throughout
Clean typography with consistent heading hierarchy (H1, H2, H3)
Dividers or spacing between sections for readability

Visual Design:

Use a professional color accent in the header (e.g., a colored banner or border)
School logo placeholder (if logo exists in system, embed it)
Consistent font sizing and bold headings
Footer with page number and document generation date


Where This Export Must Be Available
Apply this export functionality everywhere student plans appear across the system, including but not limited to:

School Account → Students Page → Student Profile/File
Teacher Account → Student File (inside class or student list)
Any other location in the app where Enrichment or Remedial plans are displayed

The export button should appear as a clearly labeled action — e.g., "Export Plan" (تصدير الخطة) — with a dropdown or modal to choose which plan(s) to export.

Technical Notes

Use a server-side or client-side .docx generation library (e.g., docx.js / python-docx depending on stack)
RTL text direction must be enforced in the Word document
File should be named clearly, e.g.: Student_Name_Remedial_Plan_2026-03-26.docx
Trigger download automatically upon generation
