Redesign the external (collapsed/preview) UI of Challenge Cards inside the "Product Intelligence Hub" page to be more structured, clean, and focused on key information only.

IMPORTANT:
This task is ONLY about the OUTER view of the card (before opening it).
Do NOT include full details or comments inside this view.

==================================================
1) CORE OBJECTIVE
==================================================

Transform the external card into a clean, highly readable, and action-oriented preview that highlights only the most important data.

The card should:
→ be easy to scan quickly
→ show critical information at a glance
→ avoid overload

==================================================
2) DISPLAY ONLY KEY DATA (MANDATORY)
==================================================

Each card must show ONLY the following:

- Challenge Title
- Reporter (المُبلّغ) — clearly visible
- Progress (visual + percentage)
- Status (via color or indicator)
- Creation Date
- Challenge Serial Number (ID)

Do NOT include:
- long descriptions
- full details
- comments content

==================================================
3) PROGRESS BAR (FULL WIDTH — CRITICAL)
==================================================

- The progress bar must:
  → span FULL width of the card
  → be clearly visible and dominant

- Include:
  - percentage (e.g., 55%)
  - status label (e.g., In Progress)

- Colors must be dynamic based on status:
  - New → neutral color
  - Under Review → blue
  - In Progress → orange
  - QA → purple
  - Done → green
  - Rejected → red

==================================================
4) VISUAL HIERARCHY
==================================================

Structure the card visually as follows:

TOP:
- Challenge Title (large and clear)

SECONDARY:
- Reporter (highlighted, not small text)
- Serial Number (subtle but visible)

CENTER:
- Progress Bar (full width)

BOTTOM:
- Creation Date
- Status indicator (if separate from progress)

==================================================
5) REPORTER VISIBILITY
==================================================

- The reporter name must:
  → be clearly visible
  → not hidden in metadata
  → styled to stand out slightly

Optional:
- include avatar if available

==================================================
6) SERIAL NUMBER (IMPORTANT)
==================================================

- Each card must show a unique Challenge ID
- Position:
  → top corner or near title

Example:
#CH-1023

==================================================
7) DATE DISPLAY
==================================================

- Show creation date clearly
- Use readable format:
  → e.g., 12 Feb 2026
- Position:
  → bottom area of card

==================================================
8) UI STYLE
==================================================

- Clean, modern, enterprise style
- Use:
  - spacing
  - soft shadows
  - rounded corners
  - consistent padding

- Avoid:
  - clutter
  - too many elements
  - dense text

==================================================
9) INTERACTIVE FEEDBACK
==================================================

- Hover effect:
  → slight elevation or highlight
- Click:
  → opens full card details (internal view)

==================================================
10) CONSISTENCY
==================================================

- All cards must follow the same structure
- No variation between cards
- Fully aligned grid

==================================================
11) RESPONSIVENESS
==================================================

Desktop:
→ grid layout

Tablet:
→ fewer columns

Mobile:
→ full width stacked cards

==================================================
12) GOAL
==================================================

Convert the card from:

→ a cluttered information block

To:

→ a clean, structured, high-signal preview

That allows the user to:
- scan multiple challenges quickly
- understand status instantly
- identify ownership
- decide which card to open
