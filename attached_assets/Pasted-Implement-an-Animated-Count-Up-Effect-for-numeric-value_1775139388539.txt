Implement an Animated Count-Up Effect for numeric values inside KPI cards (e.g., "Total Challenges") in the "Product Intelligence Hub" page.

The goal is to enhance the perception of achievement and progress through a smooth, subtle animation when the card loads.

==================================================
1) CORE OBJECTIVE
==================================================

Animate numeric values so they:

→ start from a lower value (e.g., 0)  
→ smoothly count up to the final value  

This creates:
- a sense of progress
- visual engagement
- psychological reward

==================================================
2) ANIMATION BEHAVIOR
==================================================

- Animation starts:
  → when the component becomes visible (on page load or scroll into view)

- Count-up pattern:
  → from 0 (or near value) to final number
  → smooth increment (not step-by-step jumps)

- Must feel:
  → fluid
  → controlled
  → professional

==================================================
3) TIMING RULES
==================================================

- Duration:
  → between 800ms to 1500ms (depending on number size)

- Large numbers:
  → slightly longer duration

- Small numbers:
  → faster animation

- Avoid:
  → too fast (feels meaningless)
  → too slow (feels laggy)

==================================================
4) EASING FUNCTION
==================================================

- Use easing:
  → ease-out (fast start, slow end)

Reason:
→ gives a satisfying “arrival” feeling at final value

==================================================
5) FORMATTING SUPPORT
==================================================

- Maintain correct formatting during animation:
  → thousands separators (e.g., 1,250)
  → localization (Arabic / English)

- Do NOT:
  → break number formatting during animation

==================================================
6) FINAL VALUE STATE
==================================================

- Once animation ends:
  → value must remain stable
  → no flicker or re-render

- Optional:
  → very subtle highlight or emphasis on completion (fade or slight glow)

==================================================
7) PERFORMANCE RULES
==================================================

- Animation must:
  → run efficiently
  → not trigger unnecessary re-renders

- Should NOT:
  → block UI
  → affect scrolling performance

==================================================
8) RE-TRIGGER BEHAVIOR
==================================================

- Animation should:
  → run once on first visibility

- Optional:
  → re-trigger only if component is fully re-mounted

- Avoid:
  → repeating animation on every minor update

==================================================
9) RESPONSIVENESS
==================================================

- Must work consistently across:
  → desktop
  → tablet
  → mobile

==================================================
10) ACCESSIBILITY (IMPORTANT)
==================================================

- If user has "reduced motion" preference:
  → skip animation
  → show final number instantly

==================================================
11) OPTIONAL ENHANCEMENTS
==================================================

- Combine with:
  → slight fade-in of the number
  → subtle scale-in (very light, not noticeable)

- Do NOT:
  → bounce
  → overshoot
  → flashy effects

==================================================
12) FINAL GOAL
==================================================

Transform static numbers into:

→ dynamic indicators of achievement

Without compromising:
- performance
- clarity
- professional UI feel
