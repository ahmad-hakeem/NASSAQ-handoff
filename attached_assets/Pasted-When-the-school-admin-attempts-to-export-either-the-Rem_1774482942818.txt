When the school admin attempts to export either the Remedial Plan or the Enrichment Plan, the following error appears:

"فشل تصدير الخطة. يرجى المحاولة مرة أخرى."
(Plan export failed. Please try again.)

This must be fully debugged and fixed.

Root Cause Investigation — Check All of the Following:

Is the export function being called correctly with the right student/plan data passed in?
Is the document generation library properly imported and initialized?
Are there any missing or undefined fields causing the generation to crash silently?
Is the download trigger (blob URL / file save) working correctly in the browser?
Are there any async/await issues or unhandled promise rejections in the export flow?
Is the error being caught and swallowed without a real fallback?

Fix all identified issues and ensure the export works end-to-end without errors.

Export Output Requirements
After the fix, the exported file must be available in two formats — the user chooses before downloading:

✅ PDF format (.pdf)
✅ Word format (.docx)


Document Design & Content (applies to both PDF and Word)
Header / Branding:

NASSAQ logo (نسق) — embed the app logo at the top
School name — pulled dynamically from the school's profile data
Horizontal divider line separating the header from the body

Document Title:

Clearly states the plan type: "Remedial Plan" / "Enrichment Plan" / "Both Plans"
Student name, grade, and class displayed prominently below the title

Essential Data Fields to Include:

Student full name
Grade & class
Teacher name
School name
Date of export
Academic year
Plan goals and objectives
Plan steps / activities / interventions
Notes and observations
Any performance indicators or metrics stored in the plan

Design & Formatting:

Clean, professional layout with clear H1 / H2 / H3 heading hierarchy
Consistent spacing and section dividers
RTL Arabic text direction enforced throughout
For PDF: use proper Arabic font rendering (e.g., Cairo, Tajawal, or Amiri)
For Word: set document direction to RTL, use Arabic-compatible font
Footer on each page: document name + page number + generation date

File Naming Convention:
StudentName_PlanType_Date.pdf
StudentName_PlanType_Date.docx
Example: Ahmed_Mohamed_Remedial_Plan_2026-03-26.pdf

UX Flow After Fix

Admin clicks "Export Plan" button on student profile
A modal appears with:

Plan selection: Remedial / Enrichment / Both
Format selection: PDF / Word
A "Download" button


On click, file generates and downloads automatically
If any error occurs during generation, display a specific, descriptive error message (not a generic one) so it can be debugged easily


Technical Notes

For PDF generation: use jsPDF + html2canvas or pdfmake with Arabic font support
For Word generation: use docx.js (docx npm package) with RTL paragraph settings
All export logic should be wrapped in a proper try/catch block with console error logging
Test with students who have incomplete plan data to ensure no crash on missing fields — use fallback placeholder text instead
