شكراً على التقرير التفصيلي.
المطلوب الآن هو **تنفيذ جميع الأجزاء الناقصة وتحسين الأجزاء الجزئية** بحيث تصبح صفحة **My Schedule مكتملة 100% ومتوافقة مع منطق النظام وTeacher Session Engine**.

يرجى تنفيذ جميع العناصر التالية بدقة.

---

# 1 — استكمال البيانات المعروضة في الجدول

حالياً يتم عرض:

* اليوم
* رقم الحصة
* المادة
* الفصل
* التوقيت

المطلوب إضافة الحقول التالية:

### 1.1 القاعة

عرض:

```text
room_number
```

إذا لم توجد قاعة:

```text
— 
```

---

### 1.2 حالة الحصة

يجب حساب حالة الحصة تلقائياً بناءً على الوقت الحالي.

الحالات:

```text
upcoming
current
completed
```

منطق الحساب:

```
if current_time < start_time → upcoming
if start_time <= current_time <= end_time → current
if current_time > end_time → completed
```

---

# 2 — مؤشر الحصة الحالية

يجب أن يقوم النظام تلقائياً بتحديد الحصة الحالية.

المطلوب:

* تمييز بطاقة الحصة بلون واضح
* عرض Badge

```text
الحصة الحالية
```

* إضافة زر:

```text
ابدأ الحصة
```

---

# 3 — مؤشر الحصة القادمة

يجب عرض قسم أعلى الصفحة بعنوان:

```text
الحصة القادمة
```

ويظهر:

* المادة
* الفصل
* توقيت الحصة

مع عداد تنازلي:

```text
الحصة القادمة بعد 15 دقيقة
```

منطق الحساب:

```
next_session = first session where start_time > current_time
countdown = start_time - current_time
```

---

# 4 — إضافة العرض الشهري (Monthly View)

إضافة تبويب جديد:

```text
Monthly View
```

يعرض تقويم شهري.

كل يوم يحتوي:

* عدد الحصص
* مؤشر وجود حصص

مثال:

```
3 Sessions
```

عند الضغط على أي يوم:

يتم فتح:

```text
Daily Schedule Modal
```

---

# 5 — نافذة تفاصيل الحصة

عند الضغط على أي حصة يجب فتح نافذة تفاصيل.

المعلومات المعروضة:

* المادة
* الفصل
* عدد الطلاب
* القاعة
* توقيت الحصة
* اسم المعلم
* زر بدء الحصة

زر:

```text
Start Session
```

ينقل إلى:

```
/teacher/session/start/{session_id}
```

---

# 6 — تفعيل زر "ابدأ الحصة"

حالياً الزر موجود بدون وظيفة.

المطلوب:

```javascript
navigate(`/teacher/session/start/${session_id}`)
```

عند الضغط:

يجب فتح **Teacher Session Page**.

---

# 7 — التحديث التلقائي للحصص

يجب تحديث حالات الحصص تلقائياً كل دقيقة.

تنفيذ:

```javascript
setInterval(updateSessionStatus, 60000)
```

يتم تحديث:

* current session
* next session
* status badges

بدون تحديث الصفحة.

---

# 8 — إضافة اختيار التاريخ

بدلاً من التنقل بالأسهم فقط يجب إضافة:

```text
Date Picker
```

يسمح للمعلم باختيار أي يوم.

بعد الاختيار يتم جلب:

```
GET /api/teacher/schedule/{teacher_id}?date=YYYY-MM-DD
```

---

# 9 — كشف تعديل الجدول

إذا قام مدير المدرسة بتعديل الجدول يجب إظهار إشعار.

تنفيذ:

```text
Schedule Update Detection
```

عند اكتشاف تغيير:

يظهر إشعار:

```text
تم تحديث الجدول الدراسي
```

---

# 10 — رسالة "لا يوجد حصص اليوم"

إذا لم يكن هناك حصص في اليوم المختار يجب عرض رسالة واضحة.

النص:

```text
لا يوجد حصص لهذا اليوم
```

بدلاً من الرسالة العامة.

---

# 11 — كشف تعارض الحصص

يجب إضافة منطق للكشف عن التعارض.

```
if sessionA overlaps sessionB
```

يتم:

* تسجيل الحدث
* إرسال تنبيه لمدير المدرسة

---

# 12 — تفعيل أزرار الطباعة والتصدير

الأزرار موجودة بصرياً فقط.

المطلوب:

### Print Schedule

فتح:

```
print layout
```

### Export Schedule

يدعم:

```
PDF
Excel
```

---

# 13 — تحسين استخدام بيانات Backend

الـ Backend يوفر الحقول التالية:

* class_name
* subject_name
* time_slot
* room_number

المطلوب استخدام جميع الحقول بدلاً من الاكتفاء بجزء منها.

---

# 14 — تحسين الأداء

يجب التأكد من:

* تحميل الجدول مرة واحدة
* إعادة الحساب محلياً للحالة الحالية
* عدم استدعاء API كل دقيقة

---

# 15 — التكامل مع Session Engine

صفحة My Schedule يجب أن تكون نقطة الدخول لـ:

```
Teacher Session Engine
```

لذلك يجب ربط:

```
schedule session → start teaching session
```
