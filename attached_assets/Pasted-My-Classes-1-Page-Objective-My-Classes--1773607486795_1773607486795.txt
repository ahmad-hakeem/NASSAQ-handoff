My Classes

## إدارة فصول المعلم

## 1. الهدف من الصفحة (Page Objective)

تمكّن صفحة **My Classes** المعلم من عرض جميع الفصول المرتبطة به داخل النظام، وإدارة الوصول السريع إلى طلاب هذه الفصول وملفاتهم وتقاريرهم، إضافة إلى الانتقال المباشر إلى الحصص أو الجدول الدراسي.

تعتبر هذه الصفحة **مركز إدارة الفصول الخاصة بالمعلم** حيث تساعده على:

* معرفة جميع الفصول التي يقوم بتدريسها.
* متابعة عدد الطلاب داخل كل فصل.
* معرفة موعد الحصة القادمة.
* الوصول السريع إلى قائمة الطلاب.
* فتح ملف أي طالب.
* عرض تقارير الفصل.
* الانتقال إلى الجدول الدراسي أو بدء الحصة مباشرة.

---

# 2. مصدر البيانات (Data Source)

تعتمد الصفحة بالكامل على **قاعدة البيانات الديناميكية للنظام** ويتم جلب البيانات عبر الربط بين الكيانات التالية:

* Teacher
* Teacher Class Assignment
* Classes
* Subjects
* Student Enrollment
* Timetable Sessions
* Student Profiles
* Class Reports

يتم تحميل البيانات اعتمادًا على:

```text
Teacher ID
```

بحيث يعرض النظام فقط الفصول المرتبطة بهذا المعلم.

---

# 3. ما تعرضه الصفحة (Displayed Information)

يعرض النظام بطاقة أو صف مستقل لكل فصل مرتبط بالمعلم.

لكل فصل يجب عرض المعلومات التالية:

| الحقل              | الوصف                               |
| ------------------ | ----------------------------------- |
| اسم الفصل          | اسم الفصل أو الشعبة                 |
| المادة المرتبطة    | المادة التي يدرسها المعلم           |
| المرحلة الدراسية   | الصف أو المرحلة التعليمية           |
| عدد الطلاب         | عدد الطلاب المسجلين داخل الفصل      |
| موعد الحصة القادمة | أقرب حصة قادمة لهذا الفصل           |
| حالة الفصل         | نشط / بدون حصة قادمة / يحتاج متابعة |

---

# 4. شكل عرض الفصول (Display Modes)

## 4.1 العرض البطاقي (Card View)

كل فصل يظهر داخل بطاقة تحتوي على:

* اسم الفصل
* اسم المادة
* المرحلة الدراسية
* عدد الطلاب
* موعد الحصة القادمة
* أزرار العمليات

هذا العرض مناسب للاستخدام السريع والبصري.

---

## 4.2 العرض الجدولي (Table View)

يعرض الفصول في جدول يحتوي على:

* اسم الفصل
* المادة
* المرحلة
* عدد الطلاب
* الحصة القادمة
* الإجراءات

هذا العرض مفيد عند وجود عدد كبير من الفصول.

---

# 5. العمليات المتاحة داخل الصفحة (Available Actions)

من خلال صفحة **My Classes** يستطيع المعلم تنفيذ العمليات التالية.

---

## 5.1 عرض قائمة الطلاب (View Student List)

عند الضغط على زر:

**عرض الطلاب**

يقوم النظام بفتح قائمة الطلاب المسجلين داخل هذا الفصل.

تعرض القائمة لكل طالب:

* صورة الطالب
* اسم الطالب
* رقم الطالب
* حالة الحضور الأخيرة
* مستوى المشاركة
* زر فتح الملف الشخصي

---

## 5.2 الانتقال إلى ملف الطالب (Student Profile View)

عند الضغط على أي طالب يتم فتح:

# Student Profile View

## ملف الطالب

---

# 1. الهدف من الصفحة (Page Objective)

تتيح هذه الصفحة للمعلم **الاطلاع على الملف الكامل للطالب** ضمن حدود صلاحياته التعليمية، مما يساعده على فهم أداء الطالب وسلوكه ومشاركته داخل الحصص.

كما تمثل الصفحة مركزًا لتحليل بيانات الطالب بشكل متكامل لدعم قرارات التدريس والمتابعة.

---

# 2. البيانات الأساسية المعروضة (Basic Student Information)

يعرض النظام المعلومات الأساسية التالية:

| الحقل               | الوصف                              |
| ------------------- | ---------------------------------- |
| صورة الطالب         | الصورة الشخصية                     |
| اسم الطالب          | الاسم الكامل                       |
| رقم الطالب أو الكود | معرف الطالب داخل النظام            |
| الفصل               | الفصل المسجل به الطالب             |
| المرحلة الدراسية    | الصف الدراسي                       |
| بيانات ولي الأمر    | اسم ولي الأمر ورقم التواصل الأساسي |

---

# 3. السجلات المرتبطة بالطالب (Student Records)

يعرض ملف الطالب السجلات المرتبطة بأدائه داخل النظام.

---

## 3.1 سجل الحضور

يعرض النظام:

* عدد أيام الحضور
* عدد أيام الغياب
* عدد مرات التأخير
* نسبة الحضور العامة

كما يمكن عرض تاريخ الحضور لكل حصة.

---

## 3.2 سجل السلوك

يعرض النظام:

* السلوكيات الإيجابية
* السلوكيات السلبية
* آخر ملاحظات السلوك
* إجمالي نقاط السلوك

---

## 3.3 سجل المهارات

يتضمن:

* المهارات المكتسبة
* مستوى تقدم المهارات
* المهارات التي تحتاج تطوير

---

## 3.4 سجل التقييمات

يشمل:

* نتائج الاختبارات
* نتائج الواجبات
* تقييمات المعلم

---

## 3.5 سجل المشاركة داخل الحصص

يعرض:

* عدد المشاركات
* الإجابات الصحيحة
* الإجابات الخاطئة
* معدل التفاعل

---

# 4. التحليلات الذكية داخل ملف الطالب (AI Insights)

يقوم النظام باستخدام **محرك التحليل الذكي** لإنتاج تحليلات متقدمة عن الطالب.

يعرض النظام:

---

## تحليل أداء الطالب

تحليل مستوى أداء الطالب عبر:

* التقييمات
* المشاركة
* الحضور
* السلوك

---

## مستوى المشاركة

يعرض:

* معدل مشاركة الطالب مقارنة بالفصل
* مستوى نشاطه داخل الحصص

---

## نقاط القوة

يحدد النظام المجالات التي يظهر فيها الطالب أداءً جيدًا.

مثل:

* مهارات تحليلية
* مشاركة عالية
* التزام بالحضور

---

## نقاط التحسين

يحدد النظام الجوانب التي تحتاج إلى تطوير.

مثل:

* ضعف المشاركة
* ضعف الأداء في مادة معينة
* سلوك يحتاج تعديل

---

## الخطة الإثرائية (AI Enrichment Plan)

يقوم النظام بإنشاء خطة إثرائية تلقائيًا باستخدام الذكاء الاصطناعي لتعزيز نقاط القوة لدى الطالب.

تشمل:

* أنشطة تعليمية إضافية
* مهام متقدمة
* أنشطة تطوير المهارات

---

## الخطة العلاجية (AI Improvement Plan)

يقوم النظام بإنشاء خطة علاجية لمعالجة نقاط التحسين.

تشمل:

* تمارين دعم
* توصيات تعليمية
* متابعة إضافية

---

# 5. سلوك النظام داخل صفحة ملف الطالب (System Behavior)

عند فتح ملف الطالب يقوم النظام بتنفيذ الخطوات التالية:

1. التحقق من صلاحية المعلم للوصول إلى بيانات الطالب.
2. جلب البيانات الأساسية للطالب.
3. جلب سجلات الحضور.
4. جلب سجلات السلوك.
5. جلب سجلات المهارات.
6. جلب التقييمات.
7. جلب سجل المشاركة.
8. تشغيل محرك التحليل الذكي.
9. عرض النتائج داخل لوحة تحليلية واضحة.

---

# 6. الصلاحيات داخل ملف الطالب (Permissions)

يمكن للمعلم:

* عرض بيانات الطالب.
* الاطلاع على سجلات الحضور.
* الاطلاع على السلوك والمهارات.
* الاطلاع على التحليلات الذكية.

ولا يمكنه:

* تعديل البيانات الأساسية للطالب.
* تعديل بيانات ولي الأمر.
* حذف سجلات رسمية.

---

# 7. سلوك الحالات الخاصة (Edge Cases)

### الطالب بدون سجلات

إذا لم يكن لدى الطالب بيانات كافية يظهر النظام رسالة:

**لا توجد بيانات كافية للتحليل حالياً**

---

### الطالب جديد

إذا كان الطالب جديداً في النظام:

يتم عرض البيانات الأساسية فقط حتى يتم جمع بيانات كافية.

---

# 8. تكامل الصفحة مع النظام (System Integration)

ترتبط صفحة **Student Profile** بالمحركات التالية:

* Attendance Engine
* Behaviour Engine
* Skills Tracking Engine
* Assessment Engine
* Participation Engine
* AI Insight Engine

---

# 9. تجربة المستخدم (UX Behavior)

يجب أن تكون صفحة ملف الطالب:

* واضحة
* سهلة القراءة
* تعتمد على الرسوم البيانية
* تعرض البيانات بشكل بصري بسيط

---

# 10. النتيجة النهائية المطلوبة

بعد تنفيذ هذه الصفحات يجب أن يستطيع المعلم:

1. رؤية جميع فصوله في صفحة **My Classes**.
2. فتح قائمة الطلاب لكل فصل.
3. فتح ملف أي طالب.
4. الاطلاع على جميع سجلات الطالب.
5. فهم أداء الطالب عبر التحليلات الذكية.
6. الحصول على خطط إثرائية وعلاجية مدعومة بالذكاء الاصطناعي.
