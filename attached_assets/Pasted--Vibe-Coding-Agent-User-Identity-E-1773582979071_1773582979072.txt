يمكنك إرسال الرد التالي إلى **Vibe Coding Agent** ليقوم **بتفعيل واستكمال جميع طبقات User Identity Engine وتشغيلها فعليًا بالبيانات وليس بالكود فقط**.

# Activation Plan — Complete User Identity Engine

## تفعيل محرك الهوية بالكامل وربط جميع الطبقات بالبيانات

اطلعت على تقرير حالة **User Identity Engine**.
الواضح أن **الكود مكتمل تقريبًا** لكن **البيانات والعلاقات غير مفعّلة**، لذلك أريد الآن الانتقال من مرحلة **Code Ready** إلى **System Operational**.

أريد منك تنفيذ **خطة تفعيل كاملة لجميع الطبقات الأربع** وربطها بالبيانات الحقيقية داخل النظام.

# المرحلة 1 — تفعيل Role Layer بالكامل

رغم أن الكود جاهز، إلا أن المستخدمين حاليًا يمتلكون **دورًا واحدًا فقط**.

أريد تفعيل نظام **Multi-Role Identity** فعليًا.

## المطلوب

1. مراجعة جميع المستخدمين في جدول:

```
user_identities
```

2. التأكد أن كل مستخدم لديه سجل في:

```
user_roles
```

3. تفعيل دعم **الأدوار المتعددة** بحيث يمكن للمستخدم امتلاك أكثر من دور مثل:

مثال:

```
Teacher + Parent
Principal + Teacher
Platform Admin + School Admin
```

4. إنشاء بيانات اختبار حقيقية:

* 10 مستخدمين بدورين مختلفين
* 3 مستخدمين بثلاثة أدوار

5. التأكد أن:

```
linked_roles
```

تحتوي على بيانات فعلية.

6. اختبار API التالية:

```
POST /user-roles/switch
POST /user-roles/return-to-original
GET /user-roles
```

7. التأكد أن **JWT Token يتم إعادة إصداره عند تبديل الدور**.

# المرحلة 2 — تفعيل Relationship Layer

حاليًا:

```
guardian_links = فارغ
user_relationships = فارغ
```

وهذا يجعل نظام العلاقات غير مفعل.

## المطلوب

### 1) ربط أولياء الأمور بالطلاب

لدينا:

* 102 طالب
* 102 مستخدم ولي أمر

أريد:

* ربط كل طالب بولي أمر واحد على الأقل
* بعض الطلاب لديهم ولي أمرين

يجب إنشاء بيانات داخل:

```
guardian_links
```

مع الصلاحيات التالية:

```
view_grades
view_attendance
receive_notifications
communication_access
pickup_authorization
```

---

### 2) إنشاء علاقات الإخوة

باستخدام:

* رقم الهاتف
* رقم الهوية

يجب تشغيل:

```
detect_relationships
```

لإنشاء علاقات:

```
sibling
```

بين الطلاب الذين لديهم نفس ولي الأمر.

---

### 3) تفعيل شبكة العلاقات

تأكد أن:

```
GET /relationships/graph/{entity_id}
```

يُرجع:

* الطلاب
* أولياء الأمور
* المعلمين
* الفصول

داخل **Relationship Graph**.

# المرحلة 3 — تفعيل Academic Context Layer

حاليًا الطلاب مرتبطون بالفصول فقط.

أريد ربط السياق الأكاديمي بالكامل.

## المطلوب

### ربط الطلاب بالفصول

تأكد أن كل طالب لديه:

```
class_id
```

صحيح.

---

### ربط المعلمين بالفصول

تأكد من أن:

```
teacher_class_assignments
```

مكتملة.

---

### ربط المعلمين بالمواد

يجب أن يحتوي النظام على:

```
teacher_subject_assignments
```

---

### ربط ولي الأمر بالطالب أكاديميًا

بحيث يستطيع ولي الأمر رؤية:

* الحضور
* الدرجات
* التقارير
* السلوك

عبر **Guardian Link Permissions**.
