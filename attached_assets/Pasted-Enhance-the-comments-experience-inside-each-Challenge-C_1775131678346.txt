Enhance the comments experience inside each Challenge Card in the "Product Intelligence Hub" page to provide a smooth, intuitive, and enterprise-grade interaction.

==================================================
1) INPUT BEHAVIOR (TEXT ENTRY)
==================================================

- Pressing "Enter" should:
  → move the cursor to a new line (multi-line input)
  → NOT submit the comment

- Submitting a comment must be done only by:
  → clicking a "Send" button
  OR
  → pressing "Ctrl + Enter" (or Cmd + Enter on Mac)

- The input field should support:
  - multi-line writing
  - comfortable spacing
  - clear typing area

==================================================
2) MENTION SYSTEM (@Mentions)
==================================================

- Enable @mention functionality inside comments

Behavior:
- When user types "@":
  → show dropdown list of users

- User can:
  → search by name or email
  → select user from list

- Selected user should appear as:
  → highlighted mention (styled tag inside text)

==================================================
3) PERMISSION CONTROL (IMPORTANT)
==================================================

- Mention list must respect RBAC:
  - show only users that the current user is allowed to interact with
  - hide restricted or irrelevant accounts

- If user tries to manually type unauthorized mention:
  → system should ignore or block it

==================================================
4) UI/UX REQUIREMENTS
==================================================

- Input field must:
  - be clean and minimal
  - expandable (auto-grow as user types)
  - show placeholder:
    "اكتب تعليقك هنا... أو استخدم @ للإشارة إلى شخص"

- Mention dropdown:
  - fast
  - searchable
  - keyboard navigable
  - visually clear

- Mentions styling:
  - subtle highlight
  - not distracting
  - clearly distinguishable

==================================================
5) COMMENT SUBMISSION FEEDBACK
==================================================

- After submitting:
  - clear input field
  - show new comment instantly (optimistic UI)
  - display:
    - author
    - timestamp
    - content
    - mentions

==================================================
6) ADDITIONAL ENHANCEMENTS
==================================================

- Allow:
  - editing comments (if user is owner)
  - deleting comments (based on permissions)

- Optional:
  - notify mentioned users
  - highlight mentions when viewing comment

==================================================
7) GOAL
==================================================

Deliver a professional, fast, and intuitive commenting system that:

- feels natural (like Slack / Notion)
- supports structured communication
- respects permissions
- enhances collaboration between team members
